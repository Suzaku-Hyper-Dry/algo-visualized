动态规划部分简介

动态规划（Dynamic Programming，简称 DP）是一种通过把原问题分解为相对简单的子问题的方式来求解复杂问题的方法。

动态规划的核心思想

  • 最优子结构：问题的最优解包含子问题的最优解
  • 重叠子问题：子问题会被重复计算
  • 无后效性：当前状态只依赖于之前的状态

动态规划分类

1. 线性动态规划

状态按线性顺序转移，如最长上升子序列、最长公共子序列等。

2. 区间动态规划

状态定义在区间上，通过合并小区间得到大区间的解。

3. 背包问题

经典的组合优化问题，包括 01 背包、完全背包、多重背包等。

4. 状态压缩动态规划

使用二进制数表示状态，适合状态数量较少的情况。

5. 树形动态规划

在树上进行动态规划，通常使用后序遍历。

动态规划解题步骤

  1. 定义状态：确定 dp[i] 或 dp[i][j] 代表什么
  2. 状态转移方程：找出 dp[i] 与之前状态的关系
  3. 初始化：确定初始状态
  4. 确定遍历顺序：确保计算 dp[i] 时所需的状态已计算
  5. 结果提取：从最终状态中获取答案

经典动态规划问题

问题 类型 时间复杂度
记忆化搜索 递归 + 缓存 O(n)
01 背包 背包问题 O(nW)
最长上升子序列 线性 DP O(n log n)
旅行商问题 状态压缩 DP O(n² 2ⁿ)

学习路径建议

推荐学习顺序：

  1. 记忆化搜索 → 理解递归与缓存
  2. 01 背包 → 理解基本 DP 思想
  3. 最长上升子序列 → 理解线性 DP
  4. 状态压缩 DP → 理解位运算优化
