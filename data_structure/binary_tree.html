二叉树

二叉树（Binary Tree）是每个节点最多有两个子节点的树形结构，分别称为左子节点和右子节点。二叉树是计算机科学中使用最广泛的树结构，二叉搜索树（BST, Binary Search Tree）是其最重要的变体——对于任意节点，左子树所有值 < 节点值 < 右子树所有值，这使得查找、插入、删除均可在 O(log n) 完成。

核心特性

  • 每个节点最多两子：左子节点和右子节点，结构清晰简单
  • BST 有序性质：左 < 根 < 右，中序遍历得到有序序列
  • 三种遍历：先序（根左右）、中序（左根右）、后序（左右根）
  • 经典应用：二叉堆（优先队列）、Huffman 编码、表达式树、AVL / 红黑树

遍历方式

遍历顺序BST 结果典型用途
先序根 → 左 → 右序列化/反序列化复制树、前缀表达式
中序左 → 根 → 右升序序列BST 排序输出
后序左 → 右 → 根自底向上删除树、后缀表达式

BST 操作复杂度

操作平均最坏说明
查找O(log n)O(n)利用 BST 有序性质二分
插入O(log n)O(n)从根向下定位后插入
遍历O(n)O(n)访问每个节点恰好一次
